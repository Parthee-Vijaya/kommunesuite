# Navnescreening – 13. oktober 2026

Kommunesuite er bevaret efter initiativtagerens valg. Produkterne bruger
danske funktionsnavne i familien Kommunesuite. Det samlede navn er eksempelvis
“Kommunesuite PDF-værksted”, mens kort og ikoner viser funktionsnavnet.

| Tidligere navn | Dansk funktionsnavn |
| --- | --- |
| KommunePDF | PDF-værksted |
| KommuneSurvey | Spørgeskema |
| KommuneBooking | Tidsbestilling |
| KommuneDel | Fildeling |
| KommuneSign | Underskriftsforløb |
| KommuneFlow | Arbejdsgange |
| KommuneWebTjek | Tilgængelighedstjek |
| KommuneMask | Dokumentmaskering |
| KommuneLæring | Læringsforløb |

Foreløbig screening: websøgninger på Kommunesuite, de samlede produktnavne
og de alternative fællesnavne Åbenværk, Hverdagsværk og Fællesgrej viste
ingen tydelige tilsvarende softwarebrands med de eksakte samlede navne.
Søgemaskinerne viste også beslægtede og generiske resultater.

Patent- og Varemærkestyrelsens offentlige søgeflade blev brugt i browseren
med søgeordene “Åbenværk” og “Kommunesuite”. Begge afsluttede søgninger viste
0 under “Navn og logo”. Det er ikke en fuld undersøgelse af lignende mærker,
rettighedsklasser, EU-/internationale registreringer eller uregistrerede rettigheder.

Dette er en indledende navnescreening, ikke juridisk godkendelse. Beskrivende
funktionsnavne er almindelige ord, som også kan bruges af andre. Der loves
ingen eneret til ordene eller garanti for, at navne ikke kan krænke rettigheder.
